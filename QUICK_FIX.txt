Check your terminal logs for:
  [Google OAuth Start] - Shows OAuth initiation
  [Google OAuth Callback] - Shows callback processing
  [Google OAuth] Token response status - Shows if token exchange worked

Common errors:
  • "redirect_uri_mismatch" → URI not added in Google Console
  • "access_denied" → Email not added as test user
  • "invalid_client" → Wrong credentials
